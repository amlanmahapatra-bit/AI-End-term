Aangan call agent: component map

Trigger → Input → Context → Processing → AI → Output

1 Trigger

  • Inbound call answered by Vaani agent
  • Webhook: call_started
  • Webhook: call_postprocessing

2 Input

  • Transcript
  • Caller number, start/end
  • Recording URL, entities

3 Context

  • qualified.md (rubric)
  • services.md

pricing.md is never loaded

4 Processing

  • ?token= auth, idempotent
  • Log to Supabase
  • After-hours flag (outside 10-7 IST)
  • Duration and cost

5 AI

  • Gemini Flash, JSON mode
  • qualified / not_fit / complaint / unclear
  • 8-line handoff note
  • Code-level price filter

6 Output

  • Qualified: designer email (Claim / Reschedule / Booking) + HubSpot deal
  • Complaint: front-desk email
  • AI failure: raw transcript to front desk
  • Dashboard with cost

The Cut

The agent never quotes a price. It says: "Your designer will walk you through pricing on the consultation."

Where a human sits

  • Pricing: designer at the consultation, Nikhil owns the numbers
  • Site visits and dates: designer
  • Complaints: front desk or senior staff

Extending

WhatsApp and the web form reuse Context, AI and Output; only the Trigger and Input change.
